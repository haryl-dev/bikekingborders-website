# bikekingborders-website
Year 1 Web Technologies website project built using HTML and CSS

A responsive multi-page website developed for my Year 1 SQA Web Technologies module (J1GK 47) under the SQA Computing: Software Development program.

## Project Overview
This project was created as part of my university coursework to demonstrate front-end web development skills using HTML and CSS.
The website showcases a fictional bike business, featuring product displays, company information, and a responsive user interface.

## Features
- Multi-page website structure
- Responsive layout for different screen sizes
- Product showcase pages
- Custom styling with CSS
- Images and multimedia content
- Deployed live using Netlify

## Technologies Used
- HTML
- CSS
- Netlify for deployment
